# Дневник освящения

Android-приложение (Kotlin + Jetpack Compose): чтение Библии в нескольких переводах и личный дневник освящения.

## Возможности
- Скачивание переводов Библии из открытого каталога [getBible](https://getbible.net) + импорт своего JSON-файла.
- Чтение в стиле «пергамент» (зелёные номера стихов, красные заголовки), ночная и светлая темы, размер шрифта.
- Тап по стиху(ам) → панель: цветной маркер, подчёркивание, заметка (отображается прямо под стихом), закладка, копирование, «в дневник», выделение фрагмента внутри стиха.
- Дневник с разделами: «Освящение», «Мысли для проповеди», «Молитвенные нужды» (по умолчанию) + свои разделы. К записи прикрепляются стихи.
- «Пометки»: все закладки, заметки и выделения.
- Поиск по тексту, история переходов (назад/вперёд).
- Всё хранится локально (Room). Резервная копия — в JSON-файл (Настройки).

## Сборка
APK собирается GitHub Actions (`.github/workflows/build.yml`) — скачайте артефакт `sanctification-diary-debug-apk`.
Локально: Android Studio (Koala+) → Open → Run, либо `gradle :app:assembleDebug` (JDK 17, Android SDK 34).

## Замечания
- Современные переводы с авторскими правами (например, РСП/НРП) в открытых источниках отсутствуют; их можно добавить через импорт файла в формате getBible.
- Разметка заголовков разделов (как «Павел предстаёт перед Агриппой») зависит от данных перевода и пока не отображается.
